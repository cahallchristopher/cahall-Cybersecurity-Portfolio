# OSINT Tool
A modular OSINT reconnaissance tool.

## 📁 Structure
| Folder        | Purpose                          |
|---------------|----------------------------------|
| configs/      | API keys, settings, config files |
| docs/         | How the tool works               |
| reports/      | Per-target investigation notes   |
| screenshots/  | Evidence / screenshot log        |
| scripts/      | Helper scripts                   |

## 🚀 Quick Start
```bash
bash scripts/start.sh
```
